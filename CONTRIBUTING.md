# Contributing

Thanks for your interest in LocalLink, part of the
[LocalX](https://c0degeek-dev.github.io/LocalStack/) stack.

## Ground Rules

LocalLink is original software. Do not submit code, assets, tests, docs or UI
copy copied from proprietary or leaked projects. The clean-room rules of
LocalPilot ([docs/00-clean-room.md](https://github.com/C0deGeek-dev/LocalPilot/blob/main/docs/00-clean-room.md))
apply here too.

- Keep changes scoped and focused; one concern per pull request.
- Match the surrounding code style and naming.
- Update the relevant docs when you change behavior or configuration.

## Pull Request Requirements

Each PR should include:

- what changed
- why it changed
- tests added or updated
- docs updated for any behavior, usage, configuration or developer-workflow
  change, or a note that none apply and why
- provenance note for API behavior or protocol details

## Review Checklist

- [ ] Code is original.
- [ ] Docs updated for the change (or n/a noted).
- [ ] Tests cover failure paths.
- [ ] No third-party scripts, trackers or analytics.
- [ ] No secrets in fixtures.
- [ ] No broad unrelated refactors.
